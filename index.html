Quy trình khi có file mới

  1. 1Sàng lọc: công cụ dùng lâu dài thì không gắn tháng; file theo tháng thì gắn YYYY-MM.
  2. 2Sắp xếp: lưu đúng thư mục theo mã nhóm. Push Sale tháng mới tạo thư mục 04_PUSH_SALE/YYYY-MM.
  3. 3Cập nhật bản mới: công cụ thì ghi đè đúng tên cũ, không thêm _v2, _final, -1. Push Sale đổi target giữa tháng thì lưu bản mới kèm ngày DDMM và giữ bản trước, vd PS_2026-10_Tracker_Team_1810_AVATAR_450.html.
  4. 4Bản cũ cần giữ: chuyển vào 99_LUU_TRU.
  5. 5Đưa lên GitHub: bảng dùng chung tạo repo trên GitHub, rồi nhắn Claude "cập nhật Link Tổng Hợp" để link trên trang này trỏ về GitHub. Bảng chưa có trên GitHub sẽ mở file máy.
  6. 6Sang tháng mới: tạo thư mục 04_PUSH_SALE/YYYY-MM mới, nhắn Claude cập nhật để tháng trước chuyển xuống phần "Push Sale tháng cũ"; thư mục gốc chỉ còn trang chủ + 8 thư mục.
