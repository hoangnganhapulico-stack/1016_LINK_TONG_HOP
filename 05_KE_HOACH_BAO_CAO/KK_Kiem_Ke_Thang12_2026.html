Việc trễ hạn chưa xong

5 điều bắt buộc kỳ này
  1. Không trả hàng từ 02/12; không đặt / nhận hàng từ 10/12 đến hết 21/12 (nhận lại 22/12). Đặt hàng trong thời gian này phải có BOD duyệt.
  2. Kho do cửa hàng tự đếm 100% bằng Input list kho (mục 5), xuất file Warehouse gộp vào gendat của Ajis.
  3. 1 face = 1 SKU, đủ tem PC card đúng SKU, không trộn SKU trước - sau kệ (Ajis quét PC card).
  4. Layout: đủ số location, không trùng, khớp với số dán trên gondola (kiểm bằng mục 6 trước khi gửi AM / Ajis).
  5. Trong đêm kiểm kê: không di chuyển hàng, không nhập / chuyển hàng trên hệ thống.

Hướng dẫn chi tiết từng bước

Tổng hợp từ manual Kohnan, cập nhật kiểm kê T6/2026 (bản mới nhất), hướng dẫn đổ số T6/2026 và kinh nghiệm 1016. Bấm vào hình để phóng to.

5

Công cụ Input list kho (tự kiểm 100%)

Quét barcode + gõ số lượng ngay (chống quét lặp) theo từng location → in phiếu Count specification đúng mẫu → kiểm 30% / 30% / 30% → trừ hàng xuất kho ngày KK → xuất file Warehouse dán vào gendat Ajis.

Dữ liệu hàng hóa: chưa tải

Tên + CAT lấy từ dữ liệu CHECK TỒN dùng chung, hoặc tải file INPUTLIST .xlsm (sheet MAST / 1016_Item) để dùng đúng master của file Input list. Giá Cost (cột H) lấy từ Item Master mới nhất Y san gửi - tải lên trước khi xuất file Warehouse.

6

Kiểm tra layout - số location thiếu / trùng

Tải file layout (.xlsx) → công cụ đọc bảng dải số (VD "1001 ~ 1082" + số lượng) và mọi số location trên bản vẽ, báo số trùng (kèm ô Excel), số thiếu, số ngoài dải, so số lượng khai báo; kiểm cả danh sách Sampling và Input list trong file.
