Input list kho (tự kiểm 100%)

Đang kết nối...
Quét barcode + gõ số lượng ngay (chống quét lặp) theo từng location → in phiếu Count specification đúng mẫu → double check 2 lần (SM / Chief kiểm 100%) → trừ hàng xuất kho ngày KK → xuất file Warehouse dán vào gendat Ajis.

Dữ liệu hàng hóa: chưa tải

Quản lý tải Item Master mới nhất của cửa hàng (file .xlsx hoặc .csv, có cột Barcode, Item Name, Layer1 Code, Purchase Price, Order Category) hoặc file INPUTLIST .xlsm (sheet MAST). Tên hàng + CAT + danh sách hàng ký gửi (Order Category 83) tự gửi lên máy chủ cửa hàng: mọi máy cùng nhận, quét hàng ký gửi bị chặn không vào Input list. Giá Cost (cột H file Warehouse) = cột Purchase Price, chỉ lưu trên máy đã tải - tải trên máy dùng để xuất file Warehouse.
