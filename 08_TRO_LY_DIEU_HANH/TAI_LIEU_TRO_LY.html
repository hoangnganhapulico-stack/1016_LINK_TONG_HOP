Kiến trúc đồng bộ (dựa trên bằng chứng)

Phương ánKết luậnLý do
A - Kết nối trực tiếp API / CSDLKhông áp dụng đượcKhông công cụ nào có API/CSDL máy chủ; hệ thống công ty (POS, Cloud, Portal, FAST) không có quyền API.
B - Nguồn dữ liệu chungĐÃ TRIỂN KHAIMọi bản trên GitHub Pages cùng origin hoangnganhapulico-stack.github.io → dùng chung localStorage. Trợ lý đọc thẳng khóa thật của công cụ (tracker, việc của công cụ Lịch) và đọc ảnh chụp chuẩn do cầu nối S1016 gắn vào công cụ gửi lên (Lịch, Team Admin, OrderIQ, Dashboard Sale). Thay đổi ở tab công cụ → sự kiện storage → Trợ lý cập nhật ngay (không cần F5).
B mở rộng - Supabase (tùy chọn)Đã viết + kiểm thử với máy chủ giả lậpCần khi dùng nhiều máy (máy quầy + điện thoại). Chọn Supabase vì REST sẵn (PostgREST), gói Free đủ dùng, RLS chặn truy cập bằng mã cửa hàng không nằm trong HTML. Chưa có dự án thật → chưa kiểm thử thật.
C - Bán tự động (file)ĐÃ TRIỂN KHAIChip "🔗 Trợ lý 1016 · Tải gói" ở mỗi công cụ có cầu nối → file JSON → Nhập vào Trợ lý ở máy khác. Ghi thời điểm nhập, chống nhập trùng theo mã hash file + so khớp từng khóa. Không coi là thời gian thực.
Luồng dữ liệu: Công cụ nguồn (nhập file / thao tác như cũ) → lưu khóa gốc của công cụ + S1016_SNAP_* / S1016_TOUCH → Trợ lý: adapter đọc → kiểm tra cấu trúc → chuẩn hóa (mã định danh ổn định) → so sánh với bản trước → ghi lịch sử → cập nhật màn hình + trạng thái nguồn. Lỗi đọc → trạng thái "Đồng bộ thất bại", thử lại 3 lần (2s, 5s, 15s), vẫn hiện dữ liệu tốt gần nhất kèm cảnh báo đỏ.

Quy tắc đã cài đặt

  • Mỗi loại thông tin 1 nguồn chuẩn: ca → Lịch; việc định kỳ → Team Admin; Push Sale → tracker (ưu tiên AVATAR 18/10 > ON Body 02/10 > bản NV); doanh số → Dashboard Sale; tồn/đặt hàng → OrderIQ.
  • Không cộng trùng: kết quả Push Sale khóa theo SP × NV × ngày; trùng giữa tracker chỉ tính 1 lần, khác số lượng → liệt kê "lệch giữa các tracker".
  • Chỉ cộng kết quả Push Sale có hóa đơn (Slip No.) đi kèm; còn lại "Chưa xác minh".
  • Mẫu công việc không bao giờ bị sửa; phân công / tiến độ lưu theo từng lần thực hiện.
  • Ghi ngược chỉ có 1 chỗ: tick hoàn thành việc của công cụ Lịch, mặc định TẮT; đọc lại ngay trước khi ghi, khác nội dung → hủy (xung đột).
  • Không xóa/ghi đè dữ liệu công cụ gốc: gói nhập và bản sao lưu đi vào kho riêng S1016_A_IMPORT.
  • Không lưu mật khẩu/khóa trong HTML; cấu hình đám mây chỉ lưu trên từng máy.
