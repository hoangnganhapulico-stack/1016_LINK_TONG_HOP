Nhập báo cáo bán hàng để bắt đầu phân tích

Kéo-thả hoặc chọn file xuất từ POS dạng chi tiết bán hàng (transaction detail) — từ đầu tháng đến hiện tại. Nhận cả file .xlsx và .csv (lưu ý: sheet ngân sách/chỉ tiêu ngày "Budget" chỉ đọc được khi dùng file .xlsx nhiều sheet — file .csv chỉ có 1 sheet dữ liệu bán hàng). Toàn bộ việc đọc và tính toán diễn ra ngay trong trình duyệt của bạn — file không được tải lên bất kỳ máy chủ nào.

Cột cần có: Trading DateTime, Slip No., Layer1 Code, Layer1, Item Name, QTY, Amount(Tax excl.), Amount(Tax incl.). Mỗi lần muốn xem số liệu mới, chỉ cần nhập lại file xuất mới nhất — dashboard tự tính lại toàn bộ.
