Chọn được nhiều file cùng lúc, trộn .csv và .xlsx (theo tuần hoặc theo nhóm store). File dữ liệu lớn nên dùng .csv để đọc nhanh hơn.

Dùng để phân loại SKU bán yếu: chưa có mã, hết hàng, ngưng kinh doanh, có hàng nhưng bán yếu.

File của tất cả store (.csv hoặc .xlsx)
