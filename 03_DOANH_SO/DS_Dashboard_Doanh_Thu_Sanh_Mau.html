Kohnan Parc Mall - Store 1016 · Theo dõi nhiều sảnh cùng lúc - khai báo các sảnh rồi nạp DETAIL

Nhập dữ liệu

1. DETAIL (bắt buộc)
Chi tiết mặt hàng: Sales Day, POS, Slip No., Layer1, Barcode, Item Name, QTY, Amount(Tax excl.). Khách = số Slip No. khác nhau tại POS sảnh. Nên xuất toàn cửa hàng (mọi POS) để so sánh với quầy.
2. Tồn kho PLU (tuỳ chọn)
File "1016 TỒN KHO": Barcode, Supplier Code, M.A.C, Close Qty - để tính GP%, lãi gộp và lấy Mã NCC.
3. Danh sách NCC (tuỳ chọn)
File có cột Supplier Code + Supplier Name (Mã NCC + Tên NCC) để điền tên NCC. Có thể nhập/sửa tay ở mục Danh mục NCC bên dưới.
Có thể chọn nhiều file 1 lúc (vd DETAIL 3/10 + DETAIL 4/10). Nạp lại cùng loại file sẽ thay thế dữ liệu cũ của loại đó. Dữ liệu tự lưu trên trình duyệt - F5 không mất.

Cấu hình các sảnh

Mỗi dòng 1 sảnh. Ngày để trống = tự lấy theo ngày có bán của POS đó. Nạp DETAIL toàn cửa hàng gồm đủ các ngày của mọi sảnh.
Danh mục NCC (Mã NCC - Tên NCC)
Mã NCC lấy từ DETAIL hoặc file tồn kho (cột Supplier Code). Tên NCC lấy từ file Danh sách NCC hoặc nhập tay tại đây - tự lưu, F5 không mất. Mã hàng chưa có NCC (không có trong file tồn kho) nhập Mã NCC ở bảng dưới.
